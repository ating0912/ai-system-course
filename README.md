## Week 1

主題：

## Learning Goal

本週完成最小可重現 AI 實驗流程：

1. Clone repository
2. 建立 Python 環境
3. 開啟 Jupyter Notebook
4. 執行 Baseline
5. 取得 Metric
6. 使用 MLflow 記錄實驗
7. Commit / Push

## Repository Structure

- notebooks/：課堂 Notebook
- data/：課程資料
- templates/：課堂 Evidence 模板
- docs/：環境與操作說明
