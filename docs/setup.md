# Week 1 Setup

## 1. Clone

git clone <COURSE_REPO_URL>

cd ai-system-course

## 2. Create Environment

python -m venv .venv

## 3. Activate

.venv\Scripts\activate

## 4. Install Packages

pip install -r requirements.txt

## 5. Start Jupyter

jupyter notebook

## 6. Open

notebooks/week01_baseline.ipynb

## 7. Start MLflow

mlflow ui

http://127.0.0.1:5000
